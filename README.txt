DESIGNFORGE FULL CANVAS — GitHub Pages

Upload index.html, style.css and app.js to your GitHub repository root.
Enable GitHub Pages: Settings > Pages > Deploy from branch > main > root.

This is a client-side editor:
- Full 1440x900 design artboard
- Drag, resize and select objects
- Text, frames, shapes, circles, buttons and image upload
- Layers panel
- Properties panel
- Undo/redo
- Duplicate, front/back, delete
- Zoom and fit
- Save/load using browser localStorage
- Export project JSON or standalone HTML

No Python/Flask server is required for GitHub Pages.
