DesignForge V15 — Professional Design Studio

Static GitHub Pages build. Android, tablet and Windows friendly.

V15 highlights:
- Adaptive tablet/phone/desktop workspace and uniform canvas zoom
- Fit Screen, Fit Width/Height behavior, pan, pinch zoom and reset view
- Professional design types: website, mobile UI, dashboard, social, story, presentation, poster, resume, thumbnail, business card and more
- Professional visual styles and Brand Kit
- Background Studio with solid/gradient backgrounds
- Reusable components, charts and device mockup starters
- Text, shapes, cards, buttons, frames and image layers
- Blur and background blur controls
- Smart snapping, grouping, Auto Layout and prototype links
- Responsive device previews
- Project save/import/export and PNG/SVG/HTML export

Deploy:
1. Extract all files.
2. Upload/replace the complete GitHub Pages project folder.
3. Open index.html through GitHub Pages.

No backend is required for the current static build. Cloud collaboration/team-code syncing still requires a backend service.
