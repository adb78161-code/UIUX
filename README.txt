DesignForge V6
=============
GitHub Pages / Static HTML build.

Files:
- index.html
- style.css
- app.js
- reference-ui.png

Deployment:
1. Upload all files to the same GitHub Pages folder/repository.
2. Settings -> Pages -> Deploy from branch -> select the branch and root (/).
3. Open the generated Pages URL.

No Python/backend is required for this version. It runs entirely in the browser and works on modern Android browsers and Windows Chrome/Edge.
Project data is saved in the browser's localStorage. Export creates a JSON project file.
