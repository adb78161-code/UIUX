DesignForge V10
================
V10 builds on V9 with a responsive website workflow and blur/glass controls.

New:
- Object Blur
- Background Blur / glass effect
- Soft / Medium / Strong glass presets
- PC / Tablet / Phone preview
- Responsive object width and font-size values
- Responsive website HTML export
- Mobile/tablet/PC-friendly UI
- V9 editor features retained

Responsive preview:
- PC: 1440 x 900
- Tablet: 768 x 1024
- Phone: 390 x 844

GitHub Pages:
Upload index.html, style.css and app.js to the same folder and deploy from branch root.

Note:
This is still a browser-only static editor. Cloud/team-code synchronization requires a backend/database.
