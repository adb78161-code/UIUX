Install:
1. Upload the complete folder to HTTPS GitHub Pages.
2. Open the site once online and let it finish loading.
3. Tap App → Install DesignForge.
4. If the automatic prompt is unavailable, use Chrome/Edge menu → Install app / Add to Home screen.

The App menu also provides a single ZIP download for the offline editor, project download, website download, and individual source files.
