DesignForge V9
================
Static browser-based UI/UX editor designed for GitHub Pages.

Files:
- index.html
- style.css
- app.js

V9 focus:
- Android/touch-friendly layout
- No dependency on reference-ui.png
- Lightweight startup
- Automatic localStorage recovery
- Canvas presets
- Drag objects
- 8 resize handles
- Rotation handle
- Layers
- Hide/lock
- Duplicate/delete/reorder
- Text/card/button/shape/frame/image tools
- Templates
- Multiple pages
- Preview mode
- Dark/light theme
- Undo/redo
- Project export/import
- Local save

GitHub Pages:
1. Upload all three files to the same repository folder.
2. Settings -> Pages.
3. Deploy from branch.
4. Select the branch and /(root).
5. Open the generated GitHub Pages URL.

Important:
This is a static V9 editor. Cross-account/team-code synchronization requires a backend/database and is intentionally not faked in the browser-only build.
