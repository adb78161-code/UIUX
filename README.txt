DesignForge V8
==============
Static GitHub Pages UI/UX editor.

Files:
index.html
style.css
app.js
reference-ui.png

No Python/backend required for V8.
Works with mouse/keyboard on Windows and pointer/touch events on Android browsers.

Main V8 additions:
- Reliable editor state model
- New canvas presets
- Templates
- Elements/text/image tools
- Dragging
- Inspector editing
- Layers ordering
- Duplicate/delete
- Undo/redo
- Grid/zoom/device canvas modes
- Local project persistence
- JSON export
- Responsive Android layout
