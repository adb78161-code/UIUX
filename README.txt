DESIGNFORGE STUDIO — FULL GITHUB PAGES VERSION

Files:
1. index.html
2. style.css
3. app.js

Upload ALL THREE files to the same folder/root of your GitHub repository.

GitHub Pages:
Settings → Pages → Deploy from branch → main → / (root) → Save

Features:
- Reference-inspired glass/dashboard UI
- 1440×900 design canvas
- Text, cards, buttons, shapes, circles, frames
- Image upload and image replacement
- Drag and corner resize
- X/Y/Width/Height controls
- Text size, weight, color and alignment
- Fill, opacity, radius and rotation
- Layers/search
- Duplicate, front/back, delete
- Undo/redo
- Grid, zoom and fit
- Browser save
- JSON and standalone HTML export

No Python server is required. It works directly on GitHub Pages.
