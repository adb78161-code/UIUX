V21 priorities:
- Responsive editor shell for phone, tablet and PC
- Slide-out Design / Stickers / Layers / Edit drawers
- Reliable slider-based inspector
- Reliable one-finger move + resize + rotate
- Two-finger pinch zoom + two-finger pan
- Mouse wheel Ctrl/Cmd zoom + middle/space pan
- Canvas fit and centered transforms that do not mutate design dimensions
- Device preview modes that preserve the base canvas
- Scrapbook paper, tape, memo, torn paper, polaroid and decorative stickers
- Layers, pages, grouping, auto layout, prototype links, themes, brand kit, gradients
- Image effects, export to project / SVG / PNG / responsive HTML
- Local autosave and migration from V18–V20 projects
