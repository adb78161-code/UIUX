DesignForge V29 — Canvas Studio / Offline PWA

New in V29:
- Canvas Studio: change width, height, background and gradient without deleting existing layers.
- Preset canvas sizes and a dedicated Customize button.
- Preview repaired: responsive preview controls for PC, Tablet, Phone and Canvas, with fit-to-screen behavior.
- Preview is visible on small phones too.
- App update checker refreshes the service-worker cache and reloads the new version.
- Service worker cache bumped to V29.

Install: open the site on HTTPS, let it load once online, then use App -> Install DesignForge or the browser Install app option.
