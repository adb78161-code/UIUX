DesignForge V11
================

V11 is a browser-only UI/UX and responsive website editor designed for GitHub Pages.

V11 fixes the V10 problem list:
1. Custom canvas width/height with validation.
2. Real Object Blur and Background Blur / Glass presets.
3. PC / Tablet / Phone / Custom responsive preview.
4. New Layer menu.
5. Text is available directly inside Elements.
6. Functional Home button.
7. Export: DesignForge project, SVG, PNG, responsive HTML.
8. Rotation supports 0–360 degrees.
9. Fill, text, border, opacity, radius and gradient controls.
10. Changeable logo with local persistence.

Additional:
- Layers panel with hide/lock.
- Multiple pages.
- Templates.
- Image upload.
- Undo/redo.
- Touch and mouse editing.
- Responsive per-device width/height/font overrides.
- Light/dark theme.
- No reference image is required for the editor to work.

GitHub Pages:
Upload index.html, style.css, app.js and logo.png to the same folder.
Deploy from Branch -> /(root).

Important:
The editor is static/local. Cross-account cloud projects and secure 6-digit team codes require a backend/database and are not faked in this version.
